# Матрица Эйзенхауэра

Простой веб-сервис для управления задачами по методу Эйзенхауэра.

Проект написан на чистом **HTML**, **CSS** и **JavaScript** без использования сторонних библиотек и фреймворков.

---

# Описание

Матрица Эйзенхауэра помогает определить приоритет задач, разделяя их по двум критериям:

- Важность
- Срочность

В результате пользователь распределяет задачи по четырем квадрантам.

```
                Срочно

        ┌──────────────────────────────┬──────────────────────────────┐
        │                              │                              │
        │      Важно + Срочно          │     Не важно + Срочно        │
        │                              │                              │
Важно   │      Сделать сейчас          │       Делегировать           │
        │                              │                              │
        ├──────────────────────────────┼──────────────────────────────┤
        │                              │                              │
        │     Важно + Не срочно        │   Не важно + Не срочно       │
        │                              │                              │
        │       Запланировать          │        Исключить             │
        │                              │                              │
        └──────────────────────────────┴──────────────────────────────┘

                    Не срочно
```

# Планируемые возможности

Следующие функции будут реализованы в JavaScript.

## Работа с задачами

- добавление задачи
- редактирование
- удаление
- отметка выполнения
- изменение квадранта

---

## Drag & Drop

Пользователь сможет перетаскивать карточки между квадрантами.

```
Важно + Срочно

┌─────────────────────┐
│ Закончить отчет     │
└─────────────────────┘

        ↓

Важно + Не срочно
```

---

## Автоматическое сохранение

Все изменения автоматически сохраняются в LocalStorage.

После обновления страницы данные восстанавливаются автоматически.

---

## Поиск

Планируется поиск по названию задачи.

```
Поиск

[___________________]

Результаты

• Отчет
• Позвонить клиенту
```

## Фильтрация

Фильтр позволит показывать:
